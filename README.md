# ImportNow Website Recreation

A responsive, multi-section landing page recreated from the supplied ImportNow reference for a practical assignment.

## Run locally
1. Download and extract the project.
2. Open the `ImportNow-Website` folder in VS Code or Sublime Text.
3. Open `index.html` in a browser. For a local server, use the VS Code Live Server extension.

## Files
- `index.html` — page content and semantic structure
- `style.css` — responsive layout, colors, typography and visual styles
- `script.js` — mobile navigation, FAQ accordion and WhatsApp quote form

## Tools used
- ChatGPT: planning, code drafting, debugging support and code explanations
- HTML5, CSS3 and vanilla JavaScript: implementation
- Unsplash: illustrative stock photography
- GitHub: source-code hosting (after repository upload)
- Vercel: live deployment (after deployment)

## Notes
The WhatsApp quote form opens a pre-filled message to the contact number shown on the reference site. The page uses illustrative photos and recreated layout/content; it is not affiliated with ImportNow. Replace any placeholder/demo content if the employer requests exact production assets.
